# 321Fit — Project Spec

Central repository for product specifications, feature requests, and project documentation for the 321Fit platform.

## Structure

```
project-spec/
├── specs/                  # Module and feature specifications
│   ├── modules/            # Existing module specs
│   └── features/           # New feature specs / feature requests
├── architecture/           # System architecture docs
├── CLAUDE.md               # AI assistant context for product work
└── README.md
```
