Coach

Create Training Session

Unified form for personal and group. Group-only fields hide/show with animation based on type toggle.

  • Personal / Group toggle — hides/shows group fields
  • Recurring / One-off — switches Days ↔ Date picker
  • Time picker — bottom sheet with available slots
  • Price label changes: "Price" vs "Price per participant"
Full behavior spec

Prefilled defaults

Sport: first from profile. Location: first address. Type: Personal. Payment: Cash. Max: 10, Min: 3. Days: current weekday. Date: today. Time: NOT prefilled.

Validation

Save always active. On tap: validates name, duration, price, time. Red border + label on empty fields. Auto-scroll to first error. Snackbar: "Please fill in required fields." Errors clear after 3s.

Side-effect resets

Changing duration or date after time was selected → resets time to "Select time" + snackbar notification. Prevents invalid slot selection.

Time picker (sheet)

Accordion: hours with busy labels + "2/4" partial badges. Tap hour → expand minute chips. Busy minutes greyed. Confirm button shows selected range.

Recurring

Auto-generates events 2 months ahead. Daily rolling check.

One-off

Calendar grid in bottom sheet. Past dates greyed. "Special" badge on profile.

Coach

My Training Sessions

All coach's training templates. Group and personal visually distinguished by badges.

  • Personal badge — gray, neutral
  • Group badge — cyan, shows max participants
  • All icons are monochrome SVG (not emoji)
Coach

Coach Calendar

24-hour vertical timeline, 15-min grid snap. Group and personal events visually distinct.

  • Group events — cyan border + badge "7/10"
  • Personal events — green border + athlete name
  • FAB "+" — create personal, group, or custom
  • Long press → View, Reschedule, Cancel
  • Drag & drop — same day, blocked on occupied
Behavior details

Drag & Drop Rules

Coach's own slot occupied → blocked, cannot drop. Participant conflicts → warning dialog: "2 of 7 have conflicts. Move anyway?" Coach decides.

Recurring Events

Reschedule/Cancel show 3 options: "This session only", "This and following", "All sessions". Participant count shown in warning.

Overlap Policy

No overlap allowed for coach's own events. External calendar (Google/Apple) conflicts shown side by side.

API

GET {role}/training-events/?startDate&endDate
GET coach/training-events/allowed-hours/
PATCH {role}/training-events/{id}/change-status/

Coach

Calendar Sync

Clean account list — no inline calendar toggles. Tap account → detail screen.

  • Google accounts: 3-line cards (title, email in cyan, "X of Y synced")
  • Loading state: spinner + "Fetching calendars..."
  • "+ Add Google account" (dashed border)
  • Apple: "Not connected" + inline Connect button
Connection flows

Google OAuth

Tap "+" → system Google Sign-In → OAuth → backend stores tokens → auto-creates "321 Fit" calendar → loading state → calendars fetched.

Apple CalDAV

Tap Connect → separate screen with Apple ID + app-specific password form. Backend validates → stores encrypted → fetches calendars.

Multiple accounts

Multiple Google accounts supported. Each gets its own card and detail screen. Apple: one account only.

Sync

Bidirectional. External events anonymized. Webhook (Google) + 15-min fallback. Events block booking availability.

Coach

Google Calendar Detail

Dedicated screen per account. Selectable rows — tap full row, not small toggles.

  • Color dot (Google color) + name + checkmark
  • Selection pattern: gradient bg + teal border
  • Save: primary gradient button (footer)
  • Disconnect: red text link below Save (not a button)
UX decisions

Why text link for Disconnect?

Two buttons of different importance stacked = visual conflict. Text link reduces weight of destructive action while keeping it accessible.

Why dedicated screen?

If user has many calendars (10+), inline expandable would clutter the account list. Dedicated screen = clean hierarchy.

Coach

Apple Calendar Connect

CalDAV connection flow. User must provide Apple ID + app-specific password.

  • Info banner explains what app-specific password is
  • Expandable "How to create" — 4-step guide
  • "Open Apple ID Settings" — opens Safari
  • After Connect → back to Calendar Sync with loading state → calendars fetched

App-specific password is the main friction point. Clear instructions are critical.

Full flow details

Before Join — checks

Athlete cannot join if: training is full, they have a conflicting event at this time, or balance insufficient (card).

Confirmation Modal

Tap "Join" → bottom sheet: training summary, price, payment method (Visa ••••), cancellation policy (24h free). Tap "Continue" → registered.

Payment

Card: amount held from balance immediately. Cash: just registration, no hold. Coach marks cash payment after training.

After Join

Navigates to "Joined" screen. User first in list with "You" label + gradient avatar. Event added to athlete schedule with "Group" badge.

Cancellation

24h+ before: free cancel, full refund. Less than 24h: penalty applies (same policy as personal).
