Personal Data

Intro video states (Mux)

Toast preview (foreground push)

Edit profile from Settings. Coach-side — intentionally omits Weight/Height (not needed for marketplace function).

Fields

  • Avatar (initials fallback) — tap circle or pencil → pd-avatar-sheet with 3 actions: Take photo / Choose from library / Remove photo (Medium destructive, tinted red 15%). Remove hidden when no photo.
  • Intro video — Mux direct-upload. 16:9 card with 6 visual states (idle / uploading / processing / ready / errored / pending). Tap idle → native picker (PHPickerViewController iOS / PickVisualMedia.VideoOnly Android). Client PUTs file directly to Mux (resumable 256KB chunks). Webhook drives processing → ready. See mux-integration.md. Backend stores { provider: "mux", mux_upload_id, mux_asset_id, mux_playback_id, mux_status, mux_error_code }.
  • Cover image — single 16:9, up to 10 MB. S3 single-size (no transcode). Hero fallback chain: Mux video (status=ready) → cover → Mux auto-thumbnail (status=processing/errored) → brand gradient + initials.
  • First/Last name — required, maxlength=50, trimmed. Empty on Save → inline error pattern matching DOB. Server normalizes whitespace.
  • About me — 3-line clamp, tap → full-screen editor. Server max 500 chars; client warns at 450 (matches feedback_character_counter).
  • Dropdowns: Time Zone / Home Country / Languages — all full-screen push, device-detected pre-fill at onboarding.
  • Gender: Woman / Man chips, single-select. Used for athlete-side filter in Discovery.
  • DOB — 3-wheel sheet (Day/Month/Year), year capped at currentYear − 13; strict ≥ 13y on Set — inline red banner in sheet. Prod = UIDatePicker .compact (iOS) / MaterialDatePicker (Android).

Flow states (sidebar to toggle)

  • Loading — .fs-loading shows shimmer skeleton, footer hidden.
  • Network error (initial) — .fs-network-error hides skeleton + content + footer, shows centered illustration + Retry. Required — skeleton must not loop indefinitely.
  • Saving — Save button shows inline spinner, pointer-events:none.
  • Save error — red banner above footer with Retry. Generic copy for any 5xx / network mid-save.
  • Saved — snackbar 1400ms.

Save gate (client-side validation)

  • Save button takes .is-disabled style (opacity 0.5, cursor not-allowed) when DOB inline-error visible OR intro video mux_status === "errored".
  • Tap on disabled Save → smooth-scroll to first invalid field + 600ms red flash twice + snackbar "Fix the highlighted fields". No network call fired.
  • Intro video uploading / processing states are not blockers — Save commits other fields independently; video lifecycle is async via webhooks.

Upload errors (avatar / cover)

  • File > 10 MB / wrong format / network fail → toast: "Couldn’t upload cover — file too large (max 10 MB)" or "Couldn’t upload photo — try again". 3-second dismissal. Sheet stays open so user can retry.
  • iOS / Android picker enforces type filter at OS level; toast is the second line of defense.

Server contracts the prototype does NOT model — devs implement:

  • 401 on Save — token expired → push to account-access re-auth flow with context "return-to: personal-data, restore-form-state". After re-auth, restore unsaved form + auto-retry Save once.
  • Server-side field validation echo — backend returns {field, message} per error. Map into inline error pattern matching DOB (.fit-input-error-text below the field). If field can’t be mapped (unknown key), fall back to generic .pd-save-error banner with server message.
  • Intro video lifecycle — fully webhook-driven. Client posts to /me/intro-video/upload-url → PUTs to Mux directly → posts to /me/intro-video/uploaded. Mux webhooks fire asset.ready (backend stores mux_playback_id + sends videoReady push) or asset.errored (backend stores error code + sends videoFailed push). Coach taps either push → lands here at #pd-video-group anchor. See mux-integration.md.
  • Rate limit 429 — falls into .pd-save-error with server-provided message; no per-state dedicated UI.

Languages

Full-screen push from Personal Data. Multi-select — tap toggles row, Save commits all changes.

  • Row: native · English (e.g. "Polski · Polish") — users search in either
  • Sticky footer Save — enabled only when selection differs from initial AND at least 1 is selected; shows "(N selected)" count
  • Back button: if dirty → Discard changes? sheet (Discard = Medium destructive tinted red, Keep editing = text)
  • On Save: Personal Data input shows first 2 languages or "Polski +N more"
  • Seed captured on screen load + re-captured after each Save to reset dirty state

Prototype = 30 common languages. Production pulls full BCP-47 list.

Home Country

Full-screen push from Personal Data. Same pattern as Time Zone — single-select, auto-dismiss.

  • Leading slot: flag emoji 24×18 (prod: SVG flag set from country code)
  • Row = flag + country name; alphabetical
  • Current country detected from device at account creation — pre-selected
  • Used for tax/currency derivation on backend + Search → Location filter (athlete-search.md)
  • Changing country resets the City field on Personal Data — previous city is no longer valid in the new country

Prototype uses ~35 countries covering major markets. Production pulls full ISO 3166-1 list.

Coach

Home City

Full-screen push from Personal Data. Same pattern as Country — single-select, auto-dismiss, sticky search.

  • Scoped by selected country — header subtitle "Cities in <Country>"; list re-fetches when country changes
  • No flag in row — city names are unambiguous within country scope; row = city name + checkmark only
  • Pre-fill source: reverse-geocoded from device GPS at onboarding. If location permission denied or geocode fails — field stays empty, user picks manually
  • Empty state: "No matches" when filter returns zero
  • Consumed by: Search → Filters → Location (athlete-search.md)

Prototype shows 10 Polish cities (matches Country=Poland). Production pulls paginated list from backend keyed by country_code.

Time Zone

Full-screen push from Personal Data. Single-select — tap row auto-dismisses back to Personal Data with the new value.

  • Sticky search under header — live filters list by city/region/GMT
  • Row pattern: cal-select-row — 56px, teal accent on .selected, trailing checkmark toggled by class (no hardcoded SVG state)
  • Default: current TZ detected from device at account creation — shown scrolled into view + checkmarked
  • Empty state: "No matches" when filter returns zero
  • Reusable pattern for Country and Languages selectors

Prototype uses ~20 representative TZs. Production pulls full IANA zone list from device.
