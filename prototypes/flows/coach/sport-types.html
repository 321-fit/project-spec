Sport types

Push screen opened from Sport types set-card in Settings. Curated list of 33 sports across 8 sections, + coach-created custom sports (see below).

Custom sports (updated — supersedes the old "closed list, no custom" rule). At the bottom of the list: a centered dashed "Create custom sport" prompt (when none yet) → drawer with a name → a chip appears in "Your custom sports" (also at the bottom) with a placeholder icon, selected for this coach (no "pending" state — moderation is invisible to the coach). Once ≥1 exists, the prompt collapses into a compact "+ Add" tile (sport-card sized, dashed) inside that grid. It is sent to the moderation admin (321-admin → Content → Sports → Custom/Pending tab; approve / merge / reject + icon upload).

  • Usable immediately: the coach can label their own sessions with it right away, while it's still pending — no waiting on review.
  • Gated: a custom sport is is_global=false → NOT shown in athlete search, filters or matching, and not in other coaches' pick list. Private to the creating coach unless promoted.
  • On approve: admin sets is_global=true + a real icon → it joins the canonical pool (gets a stable ID), becomes searchable/matchable for everyone. This is why the original "no custom" rule existed — the gate satisfies it (no uncurated ID leaks into discovery).
  • On reject: not destructive for the coach — it simply isn't added to the shared pool. The sport stays as the coach's private custom sport (still usable for their sessions, still hidden from athletes/others). No deletion.
  • Merge: if it duplicates an existing sport, admin merges → coach's link points to the canonical one.

Selection hints

  • Sticky search filters live across all sections; empty sections auto-hide; "No matches" if zero results
  • 2-column card grid per section with non-sticky section headers (Fitness & Strength, Racket, Team & court, Combat, Endurance, Mind & body, Recovery & therapy, Other)
  • Multi-select: .sp-card.selected only — teal border + gradient; no hardcoded tick SVGs per card (CSS-driven from class)
  • Sticky footer Save disabled until selection differs from seed AND at least 1 picked; shows "(N selected)"
  • Back → discard-sheet if dirty; Discard reverts to seed + goes to Settings
  • On Save: Settings "Sport types" subtitle shows up to 3 names, then "+N more"
  • Zero-selected hint (blue info-banner) — "Pick at least one sport so athletes can find you in search"; non-blocking, Save button already disabled
  • Many-selected hint (yellow warning-banner, threshold 8) — "Picking many can dilute your specialty — focus on what you actually coach"; non-blocking
