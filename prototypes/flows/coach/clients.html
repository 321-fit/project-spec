Coach

Clients

CRM-style client list. Root tab screen (no back arrow).

  • Bell icon with red badge (3) → Requests inbox
  • "+" icon → sheet with 3 options
  • "€50 owed" red badge — client has unpaid cash session
  • Tap client → Client Detail

"+" sheet actions:
• Create athlete profile → CRM form (New Client screen)
• Invite to app → opens native iOS share sheet directly. Prefilled: "Join me on 321Fit: https://321.fit/invite/coach_id". No intermediate screen.
• Invite to training → intermediate screen to select training template, then generates deep link with event attached.

Coach

Requests

Full-screen inbox for pending booking requests.

  • Cards with unified layout: avatar + name + training + time + location + price + payment badge
  • [Decline] [Accept] buttons per card
  • Avatar row tappable → athlete profile
  • After accept: event created, athlete added to clients if new
Coach

Client Detail

Full athlete profile from coach's perspective.

  • Header: avatar, name, location, sport chips. Message + menu buttons.
  • Stats card: Sessions | Upcoming | Revenue | Owed
  • Pending Payment: red banner if unpaid cash session exists. "Mark Paid" button.
  • Upcoming Sessions: horizontal scroll cards (220px, peek pattern)
  • Notes: coach's private notes (injuries, preferences). Editable.
  • Training History → push to full history screen
Coach

Client History

Full training history with athlete.

  • All past events: name, date/time, location, price, status
  • Completed + Paid: green label
  • Cancelled: red label, price struck through
  • Sorted newest first

Create Client

CRM card for athletes without app account.

  • First name / Last name — required
  • Phone or Email — for contact (optional but recommended)
  • Sport — dropdown from coach's sports
  • Notes — tap opens full-screen editor (injuries, preferences)

Created athlete appears in Clients list. Coach can track sessions/payments.
