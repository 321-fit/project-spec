Coach

Create Training Session

Unified form for personal and group. Group-only fields hide/show with animation based on type toggle.

  • Personal / Group toggle — hides/shows group fields
  • Recurring / One-off — switches Days ↔ Date picker
  • Time picker — bottom sheet with available slots
  • Price label changes: "Price" vs "Price per participant"
Full behavior spec

Prefilled defaults

Sport: first from profile. Location: first address. Type: Personal. Payment: Cash. Max: 10, Min: 3. Days: current weekday. Date: today. Time: NOT prefilled.

Validation (Errors state)

Save always active. On tap Save: validates name, duration, price, time. Red border + red label on empty fields (all at once). Auto-scroll to first error. Snackbar: "Please fill in required fields" for 2.5s. Error styles auto-clear after 3s so user can focus and retype. Re-typing in a field does NOT auto-clear — only Save re-validates.

Side-effect resets (Time reset state)

Changing duration or date after time was selected → resets time to "Select time" + neutral snackbar: "Time slot reset — duration changed". Prevents invalid slot selection.

Time picker (sheet)

Accordion: hours with busy labels + "2/4" partial badges. Tap hour → expand minute chips. Busy minutes greyed. Confirm button shows selected range.

Recurring

Auto-generates events 2 months ahead. Daily rolling check.

One-off

Calendar grid in bottom sheet. Past dates greyed. "Special" badge on profile.

Location picker

Tap Location field → pushes to Training Locations screen in select mode. Shows all in-person + online locations. Tap = select + pop back. Supports both physical gyms and online meeting links.

API

POST /coach/training-sessions/ (create) · PUT /coach/training-sessions/{id}/ (edit).

Error state

Network/server error → inline retry card replaces list (cross-cutting pattern, #8).

Available Hours

Coach's weekly schedule — when athletes can book training sessions. Applies indefinitely until edited. New accounts are seeded with Mon–Sun 07:00–22:00 so the screen opens populated rather than empty.

  • One row per day (Mon–Sun); checkbox toggles active/inactive
  • Active day → 1+ time intervals (start · to · end) for split schedule (morning/evening with a break)
  • + on first interval appends another below; − removes an additional interval
  • Tap time input → time picker bottom sheet (wheel UI, 15-min snap)
  • Timezone is read-only — set at account creation / Settings
  • Footer Save availability (primary brand filled — follows feedback_footer_patterns.md, not a header icon)

Validation (live per-interval):

  • End ≤ start — inline error + red outline on both inputs
  • Interval < 30 min — inline error + red outline
  • Intervals overlap on same day — red outline + "Overlaps with another interval"
  • Save is disabled while any error exists

Non-blocking warning banners:

  • No active days — amber banner, Save still allowed (temp "vacation")
  • Existing bookings outside new hours — info banner + "View sessions" → bottom sheet list. Bookings stay; only new requests are affected.

Time picker (platform-native in production):

  • iOS: UIDatePicker with .compact style — tap chip expands inline wheels
  • Android: MaterialTimePicker dialog, dial mode
  • Prototype: HTML/CSS wheel for consistent cross-platform mock
  • Snap: 15-min increments; min interval length: 30 min

Flow states:

  • Loading — 5 skeleton rows mimic day layout; footer hidden during fetch
  • Saving — Save button shows inline spinner + cursor:wait; content still interactive (prevents accidental edit)
  • Save error — red banner above footer with inline Retry; Save stays tappable as secondary retry
  • Saved — snackbar "Availability updated" (1.4s) + resets to default

Back button behavior: opens Discard changes? bottom sheet. Discard = Medium destructive (tinted red), Keep editing = text button. In production, the sheet only opens when there are unsaved changes.

HIG / a11y / theming:

  • Day row min-height: 44px for tap target (checkbox + label)
  • Time input 56px tall
  • +/− buttons visually 32×32 (matches Figma) with invisible ::before hit-area expansion to 44×44 effective
  • Dark + light themed end-to-end — skeleton shimmer, banners, wheel selection band, save-error banner, checkbox border all adapt

Scope decisions (v1): single availability for all locations · no copy-to-other-days · no quick presets · no vacation mode — see project_pending_spec_updates.md for deferred items.
