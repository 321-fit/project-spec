Coach

Create Training Session

Unified form for personal and group. Group-only fields hide/show with animation based on type toggle.

  • Personal / Group toggle — hides/shows group fields
  • Recurring / One-off — switches Days ↔ Date picker
  • Time picker — bottom sheet with available slots
  • Price label changes: "Price" vs "Price per participant"
Full behavior spec

Prefilled defaults

Sport: first from profile. Location: first address. Type: Personal. Payment: Cash. Max: 10, Min: 3. Days: current weekday. Date: today. Time: NOT prefilled.

Validation

Save always active. On tap: validates name, duration, price, time. Red border + label on empty fields. Auto-scroll to first error. Snackbar: "Please fill in required fields." Errors clear after 3s.

Side-effect resets

Changing duration or date after time was selected → resets time to "Select time" + snackbar notification. Prevents invalid slot selection.

Time picker (sheet)

Accordion: hours with busy labels + "2/4" partial badges. Tap hour → expand minute chips. Busy minutes greyed. Confirm button shows selected range.

Recurring

Auto-generates events 2 months ahead. Daily rolling check.

One-off

Calendar grid in bottom sheet. Past dates greyed. "Special" badge on profile.

Location picker

Tap Location field → pushes to Training Locations screen in select mode. Shows all in-person + online locations. Tap = select + pop back. Supports both physical gyms and online meeting links.

Coach

My Training Sessions

All templates. Pencil icon → edit (same form, prefilled).

  • Pencil → edit template (Create Session form, edit mode)
  • FAB "+" → create new
  • Non-impactful edits (name, price, max): apply silently
  • Impactful edits (time, days, location): scope picker + participant warning

Coach Calendar

24-hour vertical timeline, 15-min grid snap.

  • Day strip — colored dots under days: 🟢 personal, 🔵 group, ⚫ external
  • Group events — cyan border + badge "7/10"
  • Personal events — green border + athlete name
  • External events — gray, opacity, side-by-side with hatched unavailable zone
  • Unavailable hours — diagonal hatching overlay
  • FAB "+" → sheet: Personal, Group, Custom event
  • Long tap empty slot → same sheet, time prefilled
  • Tap event → event action sheet (personal/group/invitation)
  • Long press event → activates drag & drop (same day only)
Behavior details

Day Navigation

Tap day on strip = instant switch. Swipe day strip = scroll. Swipe content left/right = page transition (Apple Calendar). Day strip auto-scrolls to selected day.

Month View Toggle

"April 2026 ▼" — tap title + chevron expands month grid. Day strip replaced by full month calendar. Tap a day = collapse back to day strip with selected day. Same component across all calendar screens (Coach, Athlete, Booking, Invite).

Drag & Drop

Long press event → event lifts, enters drag mode. Drag within same day only. Coach's own slot occupied → blocked. Unavailable zone → blocked. Participant conflicts → warning dialog "2 of 7 have conflicts. Move anyway?" Coach decides. Drop releases event at new time.

Day Strip Dots

p=personal (green), g=group (cyan), e=external (gray). At-a-glance overview.

Unavailable Zones

Hatched diagonal pattern = outside coach's available hours OR blocked by external calendar.

External Events

Imported from Google/Apple Calendar. Full-width, opacity 0.7, anonymized (title only).

API

GET {role}/training-events/?startDate&endDate
GET coach/training-events/allowed-hours/
PATCH {role}/training-events/{id}/change-status/

  • Search: Google Places autocomplete
  • Gyms Near You: pre-fetched from Google Places API (type=gym) sorted by distance
  • Tap result → Location Details form with map preview
  • Use current location: reverse geocode user's position
  • Pick on map: opens fullscreen map for manual pin drop

When user types → "Gyms Near You" replaced by autocomplete results.

Coach

Pick on Map

Fullscreen map with two modes. Tap the pill to toggle.

  • Locked (default) — 🔒 "Pin is locked · Tap to adjust". Map scrollable but pin stays. Safe for reviewing.
  • Unlocked — 🔓 "Drag to set location · Tap to lock". Pin follows map center. Address updates live.
  • Search bar at top — tap opens search screen
  • My location button — centers map on user
  • Bottom card: reverse geocoded address
  • "Confirm Location" → Location Details form

Why locked by default: prevents accidental pin movement when user opens from Location Details to verify position.

Location Details

Used for both create and edit location.

  • Map preview (top) — tap opens Pick on Map for pin adjustment
  • Address card — "Change" → back to search (new address)
  • Location name / Description / Default toggle
  • Trash icon (header, edit mode only) → delete confirmation sheet
  • Delete sheet: warns if location used in templates — "This location is used in 3 training templates. They will need a new location assigned."
  • "Save Location" → POST (create) or PUT (edit)

Create vs Edit: same screen. Edit prefills all fields + shows trash icon. Create hides trash icon.

Coach

Home Visit

Settings for home visit training type.

  • Info banner: explains concept — coach travels to athlete
  • Travel buffer: 15/30/45/60 min chips. Applied before AND after session
  • Visual timeline: shows buffer + training + buffer = total blocked
  • Service area: optional max distance (km). Athletes outside won't see home visit

Backend: location_type='home_visit', travel_buffer_minutes, service_area_km (optional). At booking: athlete's address + distance check against service area.

Full flow details

Before Join — checks

Athlete cannot join if: training is full, they have a conflicting event at this time, or balance insufficient (card).

Confirmation Modal

Tap "Join" → bottom sheet: training summary, price, payment method (Visa ••••), cancellation policy (24h free). Tap "Continue" → registered.

Payment

Card: amount held from balance immediately. Cash: just registration, no hold. Coach marks cash payment after training.

After Join

Navigates to "Joined" screen. User first in list with "You" label + gradient avatar. Event added to athlete schedule with "Group" badge.

Cancellation

24h+ before: free cancel, full refund. Less than 24h: penalty applies (same policy as personal).
