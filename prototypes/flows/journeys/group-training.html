Group training — end-to-end
A coach creates a group template (2–50 spots, no schedule), then places it on the calendar as a one-off date or a weekly recurrence — each placement is what athletes can actually book. Weekly placements auto-generate 2 months ahead. Athletes discover & join those events from the coach profile with open registration (first come, first served — no approval). The coach manages the roster, invites more athletes, then settles & completes after the session. This map links each live screen (no copies) in flow order.
References, not duplicates — every step opens the canonical screen, so this never drifts from the source. Use the browser back button to return here.  ·  Specs: group-training.md + group-event-detail.md.
Template ≠ schedule
A template is a reusable definition only — no days, no time, no recurrence. Dates are picked later, on the calendar. One template → many placements. A template with no placement is invisible to athletes — they never see templates, only events.
Open registration
No approval — first come, first served. Card = hold on join, transferred after completion. Cash = just register; coach settles by hand.
Coach-added = owed, auto-accepted
Athletes the coach adds via Invite (in-app or CRM) join instantly — no consent step, no upfront charge. Their fee is owed and ticked off in Event completion. CRM rows carry a “CRM” badge.
No waitlist in V1
Full session = the join button is disabled (“Training is Full”). No waitlist, no notify-when-a-spot-opens.
Recurring = weekly, 60 days
Auto-generate 2 months ahead, rolling daily. Weekly only (multi-day, one time). Different weekday-times = separate placements of the same template. Min threshold warns the coach 24h out — no auto-cancel.

Place it on the calendar
The step that turns a template into sessions. Entered from the calendar FAB → “Schedule training” or from a template’s “Schedule new dates” CTA: one template chooser (personal + group) → drag-drop time grid → and for a group, the publish drawer instead of an invite: Just this date or Weekly (day-chips + Ends: Ongoing / On date), time taken from the drop. One template → many placements — the same template can run Tue 12:00 and Fri 17:00 as two separate drops. Publishing runs the conflict review: own-calendar clashes are hard-skipped, external Google/Apple ones offer Keep anyway per date.
