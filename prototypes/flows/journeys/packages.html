Session packages — end-to-end
A package is a prepaid pass (gym-membership model): the coach sells N sessions of a template at a discount, the athlete pays the full amount upfront (cash or card), then redeems visits one booking at a time. The feature spans both roles across five prototypes — this map links each live screen (no copies) in flow order.
References, not duplicates — every step opens the canonical screen, so this never drifts from the source. Use the browser back button to return here.  ·  Prefer coverage over flow order? → bird's-eye view (state × surface matrix).
Prepaid, upfront
Full amount on purchase, paid straight to the coach — the platform holds nothing back. Booking burns 1 credit — no charge at booking.
Cash or card
Card = credits ready instantly. Cash = pack reads “Pending payment” until the coach marks it received — but credits are bookable right away (he approves every booking anyway). No redeem gate.
No expiry
Unused sessions never lapse — sidesteps gift-card expiry law. Refund of unused = the coach’s call, said plainly in the buy sheet rather than implied as a guarantee.
One type per pack
A pack = N sessions of one template (personal / group / self-paced), max 3 tiers. Repeat buys stack as separate lots; credits burn oldest-first (FIFO).

Coach
Packages tab
My training sessions → segmented [ Sessions | Packages ]. Packages are their own object, not a field on the template — one card per base session, tiers listed inside. Card body → Overview; card footer (“18 sold · 6 active” / “N running low”) → straight into Buyers. Empty state → “Create a package”.

Coach
Package detail — Overview | Buyers
Pure package, no template fields. Overview = base-session row + tiers as read-only cards (€/ea · save% · N sold, leader tagged “Best seller”). Buyers = who holds it + sessions left, running-low rows amber with inline Offer renewal + a bulk nudge. No expiry field — packs never lapse. Header trash deletes the pack.

Coach
Edit one tier
A tier card’s pencil (or “+ Add package tier”) pushes its own screen: sessions stepper + € total + live math (€/session + save% vs the single price). Touches only that tier. Back = cancel, footer Save tier commits. A screen, not a sheet — the € total is typed, and a keyboard over a sheet buries both the math and Save. Max 3 tiers.

Athlete buys & uses
5
Athlete
Discover & buy a pack
Coach profile → Book training. Packs are discovered in the context of a session (no separate Packages tab) — a session that offers them shows a teal “Save with a 5-pack · from €40/session” strip. Tap → buy sheet: tier + Cash/Card + a plain-spoken note that the money goes straight to the coach and any refund is arranged with him.

Bought → book your first
Confirm opens a success sheet that hands straight off to booking, instead of dropping the athlete on a dead end. Card = ✓ “N sessions ready”; cash = ⏳ “N reserved” + “pay in person — you can still book now”. CTA Book your first session lands on the calendar with a “Booking your 1st of 5” banner.

Coach
Settle a cash pack
A cash pack is bookable from the moment it’s bought — there is no redeem gate (every booking needs the coach’s approval anyway, so blocking it twice was redundant friction). Visibility replaces the gate: an inbox notification on purchase, an “unpaid cash pack” note on the booking request he approves, and an Unpaid → Mark received marker on the card until he confirms.
