Home visit — end-to-end
A home-visit training is just a normal personal session whose location the coach set to "home visit". This journey walks the real screens across both roles, in order. Each step opens the live screen (no copies) — use the back button to return here.
References, not duplicates — every step links to the canonical screen, so this never drifts from the source.
1
Coach
Set up home visit
Settings → Locations → Home visit: enable it + pick a travel buffer (default 30 min). Singleton per coach. The coach then attaches "home visit" as the location when creating a personal session.
Open
2
Athlete
Pick the session
Coach profile → Book trainings → Personal. The home-visit session shows location "Home visit · coach travels to you". No separate format pick — it's baked into the session.
Open
3
Athlete
Pick a time slot
The booking calendar — athlete + coach availability on one grid; the coach's home-visit travel buffer already removed unavailable slots server-side.

Athlete
Confirm + your address
Booking confirm sheet (home-visit mode). Your saved address is pre-filled (Change); if none saved, "Select your address" shows and Send stays blocked until you pick one.
Open
5
Athlete
Address picker
Reached from the confirm sheet — search / saved Home / use current location / pick on map. Picked address returns to the confirm and unblocks Send. Address is attached to the event, not stored coach-side.
Open

Coach
Calendar — travel buffer
Scroll to the evening: the home-visit session is flanked by hatched "Travel · 30 min" commute blocks before and after (Google-Calendar pattern). Coach-side only.

Event detail
