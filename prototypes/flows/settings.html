Connected: account cards with details. Zero: provider cards with Connect CTAs.

  • Connected: account cards + dashed "Add" + Apple with inline Connect

Connection flows

Google OAuth

Tap "+" → system Google Sign-In → OAuth → backend stores tokens → auto-creates "321 Fit" calendar → loading → calendars fetched.

Apple CalDAV

Tap Connect → Apple ID + app-specific password form. Backend validates → stores encrypted → fetches calendars.

Sync

Bidirectional. External events anonymized. Webhook + 15-min fallback.

Google Calendar Detail

Dedicated screen per account. 4 states via toggle.

  • Selectable rows with Google calendar colors
  • "321 Fit" calendar NOT shown (auto-created)
  • Save in footer, trash icon for disconnect
  • Normal: calendars toggleable
  • Fetch Failed: no calendar list, Retry button
  • Sync Error: stale calendars, Retry Sync
  • Auth Expired: calendars disabled, Reconnect button
Coach

Apple Calendar Detail

Apple-specific error states differ from Google — no auto-refresh.

  • Normal: calendars (iCloud colors), Save + Disconnect
  • Revoked: Apple ID password changed → all app-specific revoked. "Create New Password" → reconnect form
  • 2FA Issue: 2FA disabled → yellow warning + "Open Apple ID Settings"
  • Sync Error: periodic sync failed, Retry button, calendars stale but usable

Apple Calendar Connect

CalDAV connection. Apple ID + app-specific password.

  • Info banner explains CalDAV requirement
  • Steps always visible (not expandable)
  • "Open Apple ID Settings" → Safari
  • Password: eye toggle inside input
  • Keyboard: Apple ID (email, Next) → Password (default, Go → Connect)
  • Validation: empty → red border, backend error → toast

iOS: bottom sheet for errors. Android: native AlertDialog for simple confirmations.
