Messages — simple 1:1 DM

A lightweight direct-message module (Strava-style), separate from the notification Inbox. Between connected users (athlete ↔ coach). 1:1 and group — group is created by multi-selecting people in New message (super simple, no separate "create group" flow).

  • List — conversations: avatar + name + last-message preview + time. Unread = bold preview + brand dot; read = grey check + time. Compose icon (top-right) → New message. Empty state → "New message" CTA.
  • New message — search + people you're connected with (your coaches / your athletes), each with a checkbox (multi-select). Create (top-right, enables on first pick): 1 selected → 1:1, 2+ → group chat. Strava-style, minimal effort.
  • Group thread — stacked-avatar header + "You, Marco, Julia +1 · N members"; bubbles show sender name + avatar (mine plain right). Group settings: members list + Add people + Mute + Leave conversation (vs Delete for 1:1).
  • Thread — date separators + UNREAD MESSAGES divider; bubbles (mine = faint brand tint right, theirs = surface left), read tick. Header = name + presence ("last seen…") → tap → settings. Composer: text field · send. (Attach / share-a-session "+" is hidden for now — flow to be designed later.)
  • New thread (empty) — person header + "Say hi to start".
  • Conversation settings — paired avatars · "You and X" · Mute toggle · Delete conversation (destructive, confirm sheet).

Placement / entry (to decide): reuse the existing "Send Message" actions on coach/athlete profiles + participant sheets → open a thread directly. The list needs a home — options: a Messages icon in the Dashboard header (like Strava), or a section in My Coaches. Not a new bell — Inbox stays for notifications ([[feedback_one_bell_one_inbox]]).

Reverses an earlier deferral ("no messenger yet"). Backend: net-new (conversations + messages + read state + presence + push). No realtime infra today — needs a decision (poll vs websocket/LiveKit data). Spec to be written; tasks after.
