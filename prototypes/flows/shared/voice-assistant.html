Voice Assistant — conversational canvas

The assistant is a LiveKit session (GPT-4 Realtime ↔ voice_control ↔ poly-backend via child-JWT). The screen is a chat canvas: transcript bubbles + inline rich blocks rendered from the agent's data-channel messages, all reusing our existing components. You can act by voice OR by tapping the blocks.

Colour grammar (2026-06-22 pass): the brand gradient is reserved for the AI identity (header/welcome spark), the voice control (mic / send), and the single primary commit per flow (Confirm / Accept / Create). Everything else is neutral surface so the canvas reads calmly: user bubble = faint neutral tint (not full brand), coach-card headers neutral, per-coach Book = tinted secondary, avatars tinted. Status is carried by a caption dot: 🟢 green = done (created/updated), 🟡 amber = needs your action (pending_events), 🔵 blue = question / tip (followup_options, navigate), ⚪ neutral = browsing (coach_results / slots / preview). More spacing between blocks. Don't fear non-brand colour for statuses.

Rich blocks ↔ data-channel type:

  • Coach cards — coach_results (NEW) → carousel of coach cards (reuse Search coach-card). Tap → Book / profile.
  • Slot chips — slots (NEW) → tap a time instead of dictating.
  • Follow-up options — followup_options (NEW) → when the agent needs a decision (pay cash/balance, which sport, which coach). Selection rows or chips; tap = answer.
  • Booking confirm — training_event_preview (already emitted) → reuse the booking-confirm card (Confirm / Edit).
  • Reschedule preview — training_event_update_preview (already emitted).
  • Success — training_event_created / _updated (already emitted) → success card + “View in calendar”.
  • Nav hint — agent knows app_ui_map.md → can point you to a screen (deep-link).
  • Typing — agent_status (already emitted).

Coach view (toggle above, dark theme) — same canvas, coach blocks: pending requests (pending_events, NEW — athlete + session + Accept/Decline), athlete cards (athlete_results, NEW — his clients), create-for-athlete confirm (training_event_preview, already emitted coach-side too), success / nav / typing shared. Athlete books with coaches; coach manages requests + books for clients.

Control bar states: idle (tap to talk) · listening (waveform + barge-in) · thinking (spinner) · speaking (tap to interrupt — RPC interrupt already exists) · text (typed input). Keyboard toggle switches voice↔text.
