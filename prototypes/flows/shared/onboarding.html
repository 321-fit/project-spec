Step 1 — Personal data

Avatar + first name + last name + bio. Matches live iOS — gender / DOB / weight / height intentionally dropped (deferred to Settings).

  • Avatar: 110px circle, teal-blue fallback + white user icon. Tap → native picker.
  • Name fields: placeholder pattern (no separate label).
  • Bio: 500-char textarea, label "About Me" above.
  • Back disabled on step 1 — account already exists.
Shared

Step 2 — Sports

Multi-select sectioned grid (delta vs live iOS — flat grid there, our spec calls for taxonomy).

  • Title centered: "What sports do you coach?" (coach) / "What sports do you train?" (athlete).
  • Tiles per feedback_selection_chips — gradient + teal-600 border on .selected.
  • Confirm disabled until ≥1 selected (prototype pre-selects 2 for demo).
Shared

Step 3 — Location

4 push-rows: TZ + country + city + languages. Home City retained vs live iOS — useful for search-radius defaults.

  • TZ + Country — device-detected at signup, pre-filled.
  • City — reverse-geocoded; empty + manual fallback if geocode fails.
  • Languages — locale pre-fill, multi-select.
  • Changing country resets city.
Coach

Step 4 — Gym Location (coach only)

Hub for managing locations. Empty state = subtitle + outlined Add CTA. Filled state = list of cards above the Add CTA. Tap a card → opens location form for editing.

  • Athletes skip this step. Onboarding branches: athlete → Calendar at step 4 of 4.
  • ≥1 location required to Confirm.
  • Add Gym Location → opens search/map sub-flow (5 sub-screens follow).
Coach

Sub-screen — Add In-person (search)

Search-first approach copied verbatim from coach/locations.html#s-loc-map, re-namespaced under onboarding.flow.gym.map.*.

  • Search bar — Google Places autocomplete.
  • Gyms Near You — pre-fetched from Google Places API (type=gym), sorted by distance.
  • Use current location — reverse-geocode from GPS.
  • Pick on map — opens fullscreen draggable-pin sub-screen.
  • Any nearby-gym tap → Location Details form.
Coach

Sub-screen — Pick on Map

Fullscreen map with locked / unlocked pin modes. Pill at top toggles. Bottom card shows reverse-geocoded address + Confirm.

  • Locked (default) — map scrolls under pin, pin stays.
  • Unlocked — pin follows map center, address updates live.
  • Search bar at top — tap → back to search sub-screen.
  • Confirm → Location Details form.
Coach

Sub-screen — Location Details

Final step before save. Map preview + selected address + name + description + default toggle.

  • Map preview tap → back to Pick on Map (adjust pin).
  • Change link → back to search.
  • Shortcuts at bottom: Online / Home visit — let coach jump to alternate location types from inside the in-person flow.
  • Save → flips gym list state to "filled" and returns to step 4.
Coach

Sub-screen — Add Online Location

Platform picker (Zoom / Meet / Teams / Custom) + meeting link + optional display name + optional description + default toggle.

  • Backend: location_type='online' + meeting_link + platform enum.
  • Make lat/lon optional in DB schema.
Coach

Sub-screen — Home Visit

Coach travels to athlete. Athlete's address provided at booking time. Travel buffer blocks time on either side of the session in coach's calendar.

  • Travel buffer: 15/30/45/60 min chips. Applied before AND after session.
  • Visual timeline: buffer + training + buffer = total blocked.
  • Service area (optional): max distance in km. Athletes outside don't see home-visit option.
Coach

Step 5 — Training Session (coach only)

Coach creates ≥1 bookable session. Empty state = Add only; filled state = list of session cards + pencil edit.

  • Tap Add Training Session → opens session-create sub-screen (full form copied from coach/sessions.html#s-create).
  • Tap pencil on card → opens same sub-screen in edit mode.
  • Save returns to step 5 with the new session in the list.
Coach

Sub-screen — Training Session Setup

Full create form copied from coach/sessions.html#s-create. Re-namespaced under onboarding.flow.session.create.*.

  • Training name — contenteditable.
  • Sport type — picker (defaults to one selected at step 2).
  • Location — opens Gym Location step (step 4) for selection.
  • Training type — Personal / Group toggle. Group reveals participants + schedule fields.
  • Duration — canonical fit-wheel-picker (Hour + Minutes).
  • Price — numeric input + currency suffix.
  • Schedule (group only) — Recurring (day picker) or One-off (date sheet) + Start time (slot picker sheet).
  • Payment method — Cash / Card multi-select.
  • Validation snackbar for missing required fields.
  • Save → flips session list state to "filled" and returns to step 5.

Last step. No explicit Skip — Finish completes without connecting.

  • Initial: Google + Apple Connect pills.
  • After Google connects: row shows email + "Fetching calendars…" + dashed "Add Google Account". Multi-account supported. Apple still listed beneath.
  • Google → OAuth. Apple → CalDAV push (Apple ID + app-specific password) — flow lives in coach/calendar-sync.html.
