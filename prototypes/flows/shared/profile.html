Coach accepts:
Athlete balance:
  • Personal — vertical time-grid (reuses .fit-timeline/.fit-hour, 96px = 1h). Tap a free band to place the 1h block, or drag to fine-tune (snaps to 15 min). Shows both parties' unavailability: hatched = coach off-hours + coach's booked events ("Coach busy"); solid gray = your own conflicts ("You · Yoga"). Block turns red + CTA disables over any busy range; release/tap snaps to nearest free slot. Replaces the old expandable-hour picker — mirrors prod iOS SelectSlotsView drag-n-drop, plus dual-availability + tap-to-place as improvements.
  • Group — day-driven: the strip dots the days that have a session of this template; entering auto-lands on the nearest available day. Shows the ONE session for the selected day (not a list); swiping/tapping another dotted day swaps it. Full day → dimmed card + disabled CTA; non-session day → "No session this day". Sticky Join · <day> CTA (or tapping the card) → group confirm sheet.
  • Location is per session type (the picked session pins it — this grid opens for personal in-person AND home-visit; group is day-driven, online/self-paced use a different flow):
    · In-person (setHV(false), e.g. Basketball) — constant 📍 TNT Studio reminder; strip greys out days the coach isn't at that gym (off / training elsewhere — per-day location). Two empty reasons: Wrong gym day ("Not at TNT Studio this day") vs All booked (.bk-reason-booked).
    · Home-visit (setHV(true), e.g. Padel → .bk-hv) — no gym: reminder becomes 🏠 Home visit · coach travels to you; bookable across all working hours, so no gym-mismatch empty — only the generic all-booked/off-hours reason.
  • Loading — skeleton slot cards
  • Error — inline banner with Retry

Confirm sheet — bottom sheet opened by Confirm CTA. Contains coach identity + session card + optional Note textarea + price + payment method + dynamic info line + Send Request CTA. Unified pattern with athlete Group join sheet and coach invite/schedule sheets. Memory: feedback_booking_confirm_pattern.

Payment method — segmented chips (same component as the coach's Personal/Group toggle). The session inherits the methods the coach enabled for it. There's no card hold — the athlete prepays into a 321Fit balance; online payment = reserved from that balance.

  • Cash + Card → Cash | Balance chips, Cash preselected. Cash = pay in person, nothing reserved, coach confirms after. Balance = €50 reserved from prepaid balance, refunded if declined.
  • Card-only / Cash-only → no choice; a single static "Payment" line + matching info copy.
  • Insufficient balance — when paying from Balance and funds fall short, the info line shows the shortfall and the CTA flips to "Top up balance" → athlete/balance.html (no request sent until topped up). Use the preview controls above to demo it.

States & behavior

Established coach (default)

Coach with prior sessions + reviews. Video header, 4-column stats (Rating / Reviews / Sessions / Avg price), reviews carousel with rating summary.

New coach (approved)

After admin approval but before first completed session. Stats row is replaced with a teal "New coach" badge near the name + a single "Sessions from €X" line. Reviews carousel is replaced by a quiet empty-state card — no CTA (athletes can only review after completing a session).

Header media fallback (new coach)

Video: ideal, recommended during onboarding (~2× conversion vs static). Cover image: allowed if the coach is not ready to record video. Default: brand gradient + coach initials — automatic, always works if neither uploaded. Selected in Coach Onboarding Wizard (#130).

Product rule

Coach appears in athlete discovery only after setup complete + admin approval. So "truly empty" (no name, no sports, no sessions) never reaches this screen — only media / stats / reviews have zero-states.

Book Trainings

Pushed from Coach Profile v2 "Book Training" CTA. Grouped by type (no tabs — 3–6 types, tabs were overkill). Empty types simply don't render (coach with no group → no Group section).

  • Type = colour: Personal teal, Group blue, Self-paced violet (header gradient only; Book CTA stays brand). Violet is a new token (--fit-color-violet-*) added for type differentiation — TODO promote to Figma.
  • Compact cards, tap the whole card — no inline Book button (booking confirm is always a sheet anyway). Header (icon · title · sub · price · chevron) + one strip line. Mirrors the coach sessions.html#s-list card.
  • Group — strip-right keeps availability ("Next Thu · 3/10"); special one-off = blue border + "Special · 5/20". Tap → group detail.
  • Personal — location / home-visit strip. Tap → booking time-grid → confirm sheet.
  • Self-paced — "do it anytime" strip, lower price. Tap → day-bound confirm sheet.
  • Vertical list throughout (no horizontal scroll)
  • Pack upsell strip ("Save with a 5-pack") shows only when the athlete holds no credits for that session — re-pitching a pack you already own is noise. Running low is not this strip's job: the milestone notifications (notifications-catalog.md § 1.1 — fire at 20% of the pack, floored at 1, then again at 0) land at the moment that matters and deep-link straight back to this buy sheet.
