Self-paced — overview

A cheap, online training type (own session type + own price, not a flag on a normal booking). Coach offers it generically; builds the workout per athlete after a booking. Individual by design.

Isolated WIP in shared/. In prod: offering = a session-type in the coach catalog; setup/queue live in Client Detail + Inbox; athlete sees it in Coach Detail / Dashboard. Reuses Mux (#116), session cards, fit-rating, outline-note→editor.

Coach

Offering (catalog)

Just a bookable entry point — name + price (cheaper than live) + sport. No content here (content is per-athlete at setup). One generic offering for v1.

In prod this is a 3rd type in Create Session (Personal / Group / Self-paced).

Coach

Self-paced hub (batch)

Dedicated batch view for the coach's "review day" — segmented tabs (Set up / Review / Active), each its own scroll, so it scales when a block gets long.

  • Set up = booked → tap → builder. Review = submitted → tap → review. Active = sent, athlete doing it.
  • Cards match the unified-Inbox .req-card shell (avatar + name + sub + chevron + title + meta + action) — see the Inbox screen.

Placement (decided: C-lite): events also drop into the unified Inbox (next screen); this hub is reached from a Dashboard card for batch work. Same items, filtered view.

Coach

Self-paced in the Inbox

Self-paced events live in the existing unified Inbox — no new bell, no 4th tab. Same card shell as booking requests, with a Self-paced tag to tell them apart.

  • To reply ← Set up (booked) + Review (submitted) — your actions. Single primary button per card (Set up workout / Review).
  • Waiting ← Active (athlete doing it).
  • Activity ← push-history (assigned / joined / etc.).

Maps onto our existing inbox semantics 1:1 (action-by-you vs waiting). The hub screen is just this, filtered to self-paced + tabbed for batch.

Coach

Setup builder (home)

One screen = workout title + welcome note (outline-card → editor) + the step list (compact cards, drag-reorder) + Add step + Send. Built per athlete.

  • Each step card: order · video · target badge (⏱ / ×reps / follow). Tap → focused editor.
  • Price isn't here — it's fixed on the offering at booking.

Best practice: list + focused per-step editor (not one infinite-scroll form, not a rigid wizard) — handles variable count + reorder + clarity for non-techy coaches.

Coach

Step editor (focused)

Separate screen per step with a counter «Step 2 of 3 ‹ ›» to flip between steps. Fields: name · video (Mux + optional clip / library) · Target · instructions.

  • Target = independent toggles (tap the switches in the screen): Reps × sets and Timer (hold/duration) can be on together, either, or neither. Both off = "just follow the video".
  • Rest after is its own optional field (applies regardless). A standalone "Rest" step = a step with only Timer on, named Rest.

Player behaviour (now defined — see Player): each set runs as Get-ready → work (Reps set or Timed set) → Rest → repeat per set count. Reps + Timer both on = a timed work set (e.g. max reps in 45s).

Coach

Review submission

Layout reworked (async-coaching apps: CoachNow / OnForm / Freeletics) — clips up top, athlete's words as a quote, your verdict at the bottom.

  • Clips carousel — supports multiple athlete videos; compact thumbs (play + duration), tap → full-screen player. No giant inline video.
  • No clip → a compact inline "Marked done — no clips" line (teal check), visually distinct from the note. (bug fixed: it no longer shows in the With-clip state.)
  • Athlete's note → a quote (left accent + italic), not another card — so it's not confused with status lines.
  • How the athlete felt it → the structured self-report she submitted on Complete (Intensity + Technique) surfaces here, so the coach reviews against her own read before rating. (This is the screen connected to athlete Complete — same data, both sides.)
  • Your feedback → rating + inline textarea with char counter (300). Not the note→editor pattern — it's a single bounded comment.
Coach

Client history

All self-paced with this client, by status. In prod = a section inside Client Detail (NOT the calendar).

Coach

Video library

Reuse demo clips across athletes (scale lever). Opened from the step editor's video picker. Coach-only.

Athlete

Book training — Personal tab

No new booking screen. Self-paced is just another personal session type — it shows as a card in the existing Book training screen (Personal tab, same .v6d-card as profile.html#s-book-sessions), structurally identical to a live personal card:

  • Sport icon — self-paced is tied to the sport the coach chose for the offering (same icon as any session of that sport).
  • Location strip → "Self-paced · do it anytime" (clock icon, NOT "Online" — avoids confusion with live online sessions) — reuses the live card's location-strip slot, since there's no physical place.
  • Body = a short slogan ("Custom workout, built for you") + Book. The full description moves into the Book drawer, not crowding the card.
  • Lower price; no slot-grid (no live time).

Book → confirm drawer (full description + pick a day, no time) → pay from balance → lands as a request for the coach to set up.

Deferred (remember): booking window — the coach gets N days (e.g. 2) to set it up, so the athlete's day picker is constrained to that window. To design when we revisit cancellation/refunds.

Athlete

My self-paced

Athlete's aggregated list: To do (Ready / Setting up) · Awaiting feedback · Done. Not a tab — surfaced from Dashboard + per-coach in Coach Detail.

Athlete

Welcome / intro

What the coach prepared: title · steps · ~total time · note · step preview. Then start.

  • Already paid (athlete booked) → CTA Start.
  • Coach-initiated (coach pushed it, not yet paid) → CTA Pay €12 & start.
Athlete

Player (Freeletics-style)

Deliberately minimal, one focus at a time (ref: Freeletics). Full-bleed exercise media on top; bottom-left = the one number that matters (12× reps / 00:45 timer / 20s rest) + exercise name + a gray Next: line. A single thin segment bar at the very bottom tracks the whole workout (every set + rest).

An exercise plays as a sequence: Get ready (3-2-1, voiced) → work (Reps set — tap Done; or Timed set — counts down, Pause) → Rest (voiced countdown) → next set/exercise. One action only per phase (Done / Skip) — no competing CTAs.

Header is just icon-buttons: × · voice toggle · message coach. The plan (steps + targets) lives on the Welcome overview, not crowded onto the player.

Voice cues = native TTS for get-ready + rest countdowns; prototype shows icon + caption, no real audio.

Athlete

Complete + upload

First time: structured feedback (coach-actionable, replaces plain stars): How did the intensity feel? (Too easy / Just right / Too hard — helper line says what the coach will adjust) + How was your technique? (Struggled / OK / Solid). Plus optional proof-video upload (Mux) + optional note → Submit (→ coach review) OR Just mark done.

Re-do (practice): a bought session is the athlete's forever — they can repeat it anytime. But feedback to the coach is one-time: on a re-do there's no structured report / clip / submit, just Done. Keeps the coach's review queue clean (one submission per session).

AthleteCoach

Comments thread

Per-session conversation, both sides. Scoped to one session — our first messaging surface, deliberately not a global chat.

Trim clip (optional)

Shared step after picking a source. Trim is optional — many self-paced clips don't need it; Skip uploads the full take. Clipping via Mux SDK clip API (upload full → set clip start/end), not native-only. Reuses #116.

Uploading (Mux)
