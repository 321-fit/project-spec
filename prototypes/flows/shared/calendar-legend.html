Calendar legend

Opt-in reference sheet, reached from the ? button in the calendar header (disclosure Layer 2 — the event drawer stays the primary teacher, this is never an auto-popup).

Every swatch on this screen is a real tile: the same .fit-cal-event* / .fit-cal-offhours / .fit-cal-blocked classes the timeline renders, with positioning neutralised. A legend that re-declared its own colours would drift the first time a token changed.

The two axes

  • Tint = what it is. Teal personal, blue group, neutral for anything that isn’t a training (busy time, external, other role).
  • Border = does it need me. Filled yellow + solid perimeter = act. Dashed yellow + no fill = waiting, passive. No perimeter = nothing pending.

Yellow is one lane, not two: Request (before) and Review (after) both mean “coach, act”. The pill text and the position relative to the now-line disambiguate — splitting yellow into two shades would only dilute it.

Who sees what

  • Coach — all states. coach_confirmed (proxy-accepted cash invite) renders exactly like Planned; the distinction is audit-only and surfaces in the drawer, not on the tile.
  • Athlete — everything except Review: an athlete has no completion action, so the server state is mapped to Finished at the API layer.
  • Group events — Planned / Review / Missed / Finished only. Request and Awaiting don’t exist there: joining a group needs no handshake.

Zones

  • Off-hours (.fit-cal-offhours) — outside availability. Flat wash, full-bleed to the screen edge, no radius, dimmed hour labels, one centered label per contiguous band. A state of the day, not an object on it.
  • Blocked (.fit-cal-blocked) — taken inside working hours. Diagonal hatch, inset and rounded like a card. Hatch is reserved for “busy” so the pattern keeps exactly one meaning.
  • The grid is always 00:00–24:00, so day height never depends on availability; the view auto-scrolls to the now-line, or to the first available hour.
  • Athlete calendars carry no off-hours shading — an athlete has no availability, so there is nothing to grey out.
