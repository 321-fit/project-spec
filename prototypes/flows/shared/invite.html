Invite to 321Fit (global)

One global invite screen, reused from every entry point — Settings (Invite a coach / Invite a friend), My Coaches, Clients. The entry label adapts; the destination is always this screen. Role-agnostic: athlete = light, coach = dark.

QR tab — avatar + name + QR (AppsFlyer OneLink) + Copy link / Share (native sheet).

Contacts tab — same primitive as coach Clients import: permission prompt → connect → multi-select list with On 321Fit tags + Select all → footer Invite N opens the native share drawer (WhatsApp / Messages / Copy / More) with your OneLink. Nothing is sent automatically.

Invited tab — people who joined through your link (generalised coach→coach referral list). Each row shows how they joined (as coach / athlete) + a Message action → opens a chat with them (messages.html). Joined-only; rewards/pills deferred to Phase 2 per project_invite_a_coach.

Backend: GET /me/referral-link → {url, token}; GET /me/invites → joined list; contacts match endpoint (hash phone → on-app flag); signup accepts referral_token. All additive.
