Balance

The athlete spending mirror of the coach Earnings screen — now built on the same canonical ledger kit (.fit-txn* / .fit-filter-chip / .fit-stat-strip / .fit-empty-state in fit-ui.css), flipped: athlete spends (out) and tops up (in), no payouts.

  • Hero — available balance + Top up (vs coach’s Withdraw). Filled brand-gradient (“money lives here”). Role-specific, kept custom (.bal-hero).
  • This-month summary — canonical .fit-stat-strip: Spent / Topped up / Sessions.
  • Filter chips — All / Top-ups / Spent / Refunds (canonical .fit-filter-chip, client-side filter on data-txn).
  • Rows — .fit-txn with intent icons: spend --out (gray minus), top-up --in (teal plus), refund --info (blue, teal plus). Tap → detail.

Reached from: Settings → Payments → Balance, and the Dashboard balance card.

Top-up opens the Stripe top-up sheet (payment-backend). Auto-top-up config TBD. Money wire = minor units (memory: money-serialization).
