Balance

The athlete spending mirror of the coach Earnings screen — same .bal-txn ledger grammar, flipped: athlete spends (out) and tops up (in), no payouts.

  • Hero — available balance + Top up (vs coach’s Withdraw). “Auto top-up” note.
  • This-month summary — Spent / Topped up / Sessions count.
  • Filter chips — All / Top-ups / Spent / Refunds (client-side filter on data-txn).
  • Rows — spend = gray minus, top-up + refund = teal plus; icon colour by type (spend gray / top-up teal / refund blue).

Reached from: Settings → Payments → Balance, and the Dashboard balance card.

Top-up opens the Stripe top-up sheet (payment-backend). Transaction detail + auto-top-up config are TBD. Money wire = minor units (memory: money-serialization).
