ATHLETE

Athlete Home

Top → bottom priority: Balance · Next training · Pending requests · Recommended · Recently viewed · Activity teaser.

Balance card — always visible. Atlhete has no income, only spend. Card shows current sum, last top-up time, Top up + Transactions actions. Goes red when €0 with pending requests.

Decision: do not approximate "≈ N sessions left" — sums up confusing because of variable session prices. Plain € number is honest.

Next training — most actionable. Tap → event detail. Compact: avatar + sport + duration + location + when. "When" colored teal for emphasis.

Awaiting confirmation — pending booking requests sent to coaches. Each row shows when sent (4h ago, yesterday) — hint to user if it’s been too long. Tap → event detail.

Recommended — hybrid sport + location. Fallback to "top rated nearby" if sport types empty. Carousel cards: image (placeholder gradient), distance badge, favorite heart, name, sports, rating, “from” price.

Cards show distance because location is half the recommendation logic — makes “why this coach” obvious.

Recently viewed — continuation pattern. Atlhete opened coach profile but didn’t book → here’s a quick way back.

Activity teaser — drives traffic to Profile tab. Full stats live there.

States:

  • Welcome — first-run; 4-step checklist (Pick sports → Personal details → Top up → Find first coach)
  • Low balance — €0 with pending requests; balance card red, focused CTA
  • Idle — has balance, no upcoming; empty next-training with Find/My-coaches CTAs
  • Zero — clean state; balance OK, no bookings, no pending, no recent
  • Loading — skeleton on first fetch
  • Error — offline banner + cached data
ATHLETE

Sessions to rate

Completed sessions waiting for athlete’s review. Athlete-side equivalent of coach’s “Sessions to review” queue — both close the post-session loop, but different action.

Each row: coach + sport + duration + date · time + location + “Ended N ago”.

Actions: Skip (dismiss without rating) or Rate now (opens stars + free-text sheet — separate flow).

Sorted oldest-first so atlhete doesn’t leave week-old sessions sitting forever.

Reached from Notifications “Rate your session” tap or from Profile → Training history (“Leave review” CTA on completed cards).

ATHLETE

Notifications inbox

Same pattern as coach inbox — grouped by date (Today / Yesterday / older), unread items have left-side teal background + blue dot on right.

Athlete notification types:

  • Confirm — coach approved your request (green)
  • Decline — coach rejected, often with note (red)
  • Soon — session starts in N min (blue clock)
  • Review — rate your completed session (yellow star)
  • Balance — top-up needed (red card icon)
  • Match — new coaches match your filters (purple search)

Tap routes to relevant screen: confirm/decline → event detail · soon → event detail · review → rate sheet · balance → top-up · match → Search filtered.
