Profile (tab 5)

Built as a trimmed mirror of the coach Profile — same .cp-* grammar (identity row, stat strip, warm section heads + edit pencils, .fit-stat-tile group), minus the video/cover hero and the coach-only maturity / reviews-received / price blocks.

  • Identity (always visible) — avatar + camera pip + name + location → Personal Data.
  • Stat strip — Sessions · Hours · Streak (athlete aggregate; no rating/price).
  • My sports — edit pencil → Sport Types (green chips with the sport icon set).
  • About me — short bio → Personal Data.
  • Tiles — quick links to content + Settings sub-modules: Training history, My coaches, Calendar sync, Balance.
  • My reviews — reviews the athlete left to coaches (coach name + stars + text).

Everything theme-adaptive (light default for athlete). Settings gear → settings.html. Personal Data + Training history screens still TBD (stubbed). Achievements deferred to Phase 2.

Role switch — first time

The top-left chip is the role switcher (as in the live app). On the first switch to a role whose profile doesn't exist yet, this confirmation drawer appears; subsequent switches are instant (no sheet). Copy per Настя.

  • athlete → coach (heavy): confirm → create coach_profile → coach onboarding (sports · sessions · gym · available hours).
  • coach → athlete (light): confirm → create athlete_profile → switch instantly.
  • "First time" = the target role's profile doesn't exist yet — no extra flag; profile existence is the gate.
  • Drawer, not a center modal — center modals read as destructive in our system; this is additive. Reuses the calendar cross-role sheet pattern.
  • Backend reality: registration already creates only athlete_profile — the second role is created lazily on confirm (not both-by-default).

Switcher + sheet shown here on the athlete profile (athlete→coach is the meaningful path). Mirror to coach/profile.html for coach→athlete once approved.
