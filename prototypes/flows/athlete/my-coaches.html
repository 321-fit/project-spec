My Coaches

Tab 5 (people icon). The athlete's relationships with coaches — distinct from Search (discovery). Reuses the Search coach-card (photo + name + ❤️ + rating), swapping discovery info (distance / availability / bio) for a relationship line.

  • No languages on the card — languages live only on the full coach profile. The meta line shows sport only; the location line carries a country flag (🇨🇾) in place of the pin icon — the flag doubles as the country cue.
  • Cash owed badge — coaches with an unpaid cash balance get a red fit-badge-danger «€70 owed» chip next to the name (same pattern as the coach's Clients list). Tapping the card → Coach Detail, whose «Cash owed» section lists the individual sessions. No badge when nothing is owed.
  • Training with — coaches with an active relationship. Relationship line by priority: upcoming session (Next: …) → pending request pill (Awaiting confirmation) → history (12 sessions · last Apr 2). Right action: Book → booking grid.
  • Saved — favourited (❤️ from Search) but not booked yet. Action: Book.
  • Tap a row → coach profile (s-coach-v2). Next: a per-coach relationship detail (sessions with them / hours / spent / history) — mirrors the coach's Client Detail. Aggregate "me" stats live in Profile (Dashboard avatar).
  • Empty — illustration + "Find a coach" → Search. Loading — skeleton rows. Error — inline banner + Retry.

Navbar: Dashboard / Search / ✨Assistant (center) / Calendar / My Coaches. Profile is reached via the avatar on Dashboard, not a tab.

Backend: list endpoint TBD — verify against live API before issues (likely GET /v1.0.0/athlete/coaches/ + favourites). Reuse, don't invent the contract.

Package Detail

One pack of one session type. Symmetric with the coach's view of the same pack (coach/clients.html #s-pkg-detail) — same summary, same ledger, different action.

  • Summary leads with the number that drives a decision — "2 left" — and the bar is scoped to the current (unexhausted) pack, not lifetime. A lifetime denominator creeps to "900 of 920" and reads ~97% full — nearly done — for the athlete who's been loyal longest, and at that scale it can't separate "14 left" from "2 left". Lifetime lives in the Purchases header instead ("2 packs · €220").
  • One activity stream — a purchase (+5) and a session (−1) are events on the same credit account, on canonical .fit-txn rows (icon + name + location + date · time + amount), same grammar as the balance ledger. Detail shows the 3 most recent + See all N; History carries chips All · Sessions · Purchases.
  • A separate Purchases section was tried and removed — it broke at ~20 lots just like the log, and per-lot status isn't actionable (FIFO picks the lot, not you).
  • Status is derived from the lots (Pending payment / N left / Used up), never stored. Used up → the CTA becomes "Buy again" — offering "Book next session" on a pack with no credits would burn one that doesn't exist.
  • An unpaid cash pack still shows Book your 1st session — cash packs are bookable while pending (the coach approves each booking anyway).

Package History

The full redemption log for one pack — every −1 session, combined across lots in FIFO order (oldest credits burn first). Reached from See all; back returns to the pack.

  • Exists so the pack detail stays scannable: at 900 redemptions the log can't live inline without burying the purchases and the summary.
  • Rows are illustrative/sampled.

Coach detail (relationship)

Reached by tapping a coach in My Coaches. The athlete's relationship with one coach — mirror of the coach's Client Detail, athlete-side.

  • Stats strip — Sessions · Hours · Spent · Owed (red, cash debt — symmetric to the coach's "Owed").
  • Cash owed — horizontal-scroll list of unpaid cash sessions (can be several; total = Owed stat). Mirrors the coach's Pending Payments, but athlete-side: no "Mark paid" (athlete pays in person), just "Pay in person".
  • Upcoming — coach-style session cards (name · date·time · location · price), horizontal scroll, tap → calendar event.
  • My note — athlete's private note about the coach (mirrors coach's notes about clients). Outline card → editor (stub).
  • Training history — preview link → pushes s-coach-history (separate screen, keeps detail uncluttered — same pattern as coach Client Detail).
  • Your review — per-coach (one, editable). Has review: stars + text + Edit → composer (edit). No review yet (≥1 completed session): CTA "Write a review" → composer (write). Hidden if 0 completed sessions. (Per-session quick rating lives in the Dashboard rate-queue, not here.)
  • Sticky Book → booking grid. Profile › (top-right of identity) → public coach profile s-coach-v2.

Aggregate "me" stats (total across all coaches) live in Profile, not here. This screen is per-coach.

Training history (push)

Full chronological list of completed sessions with this coach. Pushed from the Coach detail history link.

  • Each row: session · date · time · location · price.
  • Status line = the per-session quick rating you gave (★ score) or "Not rated". No per-session written review — the written review is per-coach (one), left from Coach detail.

Review composer

Written review = per-coach, one, editable. Full-screen modal overlay — dismiss with × (close), not a back chevron: it's commonly opened from a push (next-day deep-link), so there's no screen to go "back" to (per feedback_back_vs_close). Not a drawer — text input in a bottom sheet gets cramped by the keyboard (feedback_screen_vs_sheet_vs_toast). Coach full name in the prompt so a push recipient knows which coach.

  • Stars prefilled from the athlete's latest session rating (they may have trained several times before reviewing) — tappable to change.
  • Text = notepad-style contenteditable, optional. Tags/chips deferred to v2 (need a curated pool).
  • Write: Post → snackbar "Review posted" → back to detail (now has-review). Edit: Update → "Review updated"; Delete → "Review deleted" → detail shows the Write CTA again.
  • Error → inline banner + Retry (CTA stays). Verified: composer only reachable after a completed session.

Entry points: push next-day after 1st completed session ("How was training with Maria?") → composer; or the "Write a review" CTA on Coach detail.
